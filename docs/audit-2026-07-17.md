# Codebase audit — 2026-07-17

Full read-only audit of src/ (8 files, ~2,300 LOC), shaders/ (9 .fx), i18n, docs, manifest.
Statuses updated as fixes land. Severity: HIGH / MED / LOW / INFO.

## Correctness

- ✅ **C1 HIGH — RT leak when stage list ends up empty** (`RenderPipeline.Apply`): `AnyEffectActive` checks config only, but stages have runtime gates (outdoors, water present, lights, god-ray amount). E.g. only CloudShadow on + walk indoors → scene captured, no stage runs, final `sb.Begin` reopens with `_sceneRT` still bound → later draws go into the scratch RT. **Fixed: restore `target` when no stage ran.**
- ✅ **C2 HIGH — mid-pass exception leaves batch unbalanced then rethrows out of catch**: recovery `sb.Begin` could throw again uncaught; device left on stage RT. **Fixed: guarded End in catch + `SetRenderTarget(target)` restore.**
- ✅ **C3 MED — TextEntryMenu keyboard subscriber leak** when menu closed externally (event/other mod). **Fixed: `cleanupBeforeExit` → Unsubscribe.**
- ✅ **C4 MED — config.json values never clamped** (GMCM ranges protect UI only): `GodRaysDecay > 1` → exponential additive white-out; negative opacities → artifacts. **Fixed: `ModConfig.Clamp()` called after ReadConfig + on GMCM save.**
- ⏳ **C5 MED — transpiler keys on exact float `1E-06f`**: correct today; silently breaks (blobs return) if a game update changes the constant. Suggested: launch-time IL sanity check that logs a warning.
- ⏳ **C6 LOW — saved "looks" capture only ~40% of settings** (bloom/grade/rays/fog): user decision needed — extend NamedProfile to all effects, or label as color-look-only.
- ✅ **C7 LOW — light-path shadows skipped the OnWater guard** the sun path has. **Fixed.**
- ⏳ **C8 LOW — RenderPipeline/ShadowRenderer never disposed on shutdown** (process-exit leak only).
- ℹ️ C9 — event-race hygiene fine; GMCM Save updates ForceBufferDraw but not FreezeGameWater (harmless, self-heals per frame).

## Structure / refactor (deferred — do with a test cycle)

- **S1 — split RenderPipeline (854 lines) into per-stage `IEffectStage` classes** with a `FrameContext`; compute active list BEFORE `sb.End` (structurally prevents C1); fold `Pass`/`DrawFull` (byte-identical) into one.
- **S2 — shared `LightQuery` helper**: 3 near-identical loops over `Game1.currentLightSources` (BuildLightList / TryGetLightUV / DrawLightShadows) with the same screen-UV + inverse-color math.
- **S3 — extract tile-mask builder**: BuildOccluderMask/BuildWaterMask are the same function with a different predicate; DrawObjectShadows repeats the in-viewport test 5×.
- **S4 — GMCM helper**: `RegisterGmcm` repeats the 3-line option pattern ~30×; a `Slider(key, get, set, min, max)` helper halves it and enforces the i18n key convention.
- **S5 — tuner**: Reflow() is fine as a layout script; extract AddToggle/AddSlider helpers that manage `y` internally. Highest-leverage idea: one declarative setting table shared by GMCM + tuner (each setting is wired 3× today). ✅ **`gameWindowSizeChanged` → Reflow() added** (panel used to stay at the old edge after resize).

## Performance

- ✅ **P1 MED — per-frame allocations in Apply()**: stage `List` + up to 9 delegate allocations per frame. **Fixed: delegates cached once, list reused.**
- ✅ **P2 MED — `content.Load` per clump per frame** (DrawResourceClumpShadow): cached instance, not a disk hit, but string-normalize + dict lookup × clumps × 60fps. **Fixed: texture cache dictionary.**
- ✅ **P3 MED — banded shadows draw-call amplification**: bands(6–18) × taps(5) = 30–90 draws per caster; **blur==0 still drew 5 identical stacked copies. Fixed: single-tap path when blur ≤ 0.** Further reduction (fewer bands for opaque silhouettes, RT-once-per-frame) deferred.
- ⏳ **P4 LOW — auto-exposure GetData sync point** (mitigated by frame-late read; meter every 4th frame if it ever profiles hot).
- ⏳ **P5 LOW — water/occluder masks rebuilt every frame** even when viewport tile-origin unchanged; cache the key.
